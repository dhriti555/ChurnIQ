About ChurnIQ

A focused machine-learning tool built to help telecom teams reduce customer attrition.

The Problem

Customer churn is one of the most expensive problems in the telecom industry. Acquiring a new customer typically costs several times more than retaining an existing one. Identifying customers who are likely to leave — early enough to intervene — can save significant revenue.

ChurnIQ turns that challenge into a simple, interactive prediction: feed in a customer’s profile and receive an immediate risk assessment backed by a trained decision-tree model.

What We Built

ChurnIQ is a lightweight Flask application that wraps a scikit-learn Decision Tree Classifier trained on the public Telco Customer Churn dataset. The interface is deliberately clean: no complex dashboards, no account system — just the form, the result, and supporting context pages.

  • 19 carefully chosen input features
  • One-hot encoding aligned with the training pipeline
  • Instant probability score and clear risk label
  • Fully local inference — your data never leaves the server

Tech Stack

BackendFlask 3
MLscikit-learn · pandas · numpy
FrontendHTML5 + modern CSS
ModelDecision Tree Classifier

Design Philosophy

We kept the experience focused and classy: a dark theme with subtle gradients, clear typography, and responsive layouts. Every page shares the same visual language so the product feels cohesive rather than a collection of disconnected screens.

No unnecessary JavaScript frameworks. No external analytics. Just a fast, elegant tool you can run locally or deploy in minutes.
